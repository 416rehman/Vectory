About this tool

Free Vector config builder and visualizer

Visualize and generate Vector configurations.

Create a Vector configuration from an empty canvas, or import YAML, JSON, or TOML and see how sources, transforms, and sinks connect. Vector collects, transforms and routes observability data such as logs and metrics. This visual pipeline builder helps you edit its configuration and generate a file for your own Vector installation.

This tool works entirely in your browser. It does not upload or automatically save configurations. Local checks cannot replace validation by the installed Vector binary.

Build a pipeline or visualize an existing config.

Start or import. Begin with a blank configuration, open the labeled synthetic example, paste code, or choose a local file up to 1 MiB.

Trace and edit. Add sources, transforms and sinks, connect their inputs and outputs, and inspect the event flow. Switch between the graph and code editor. The code view keeps every supported unknown setting available for direct editing.

Export deliberately. Download YAML, JSON, or TOML for your own Vector environment. Nothing on this page publishes a configuration or activates a device.

A few things to know.

Can I use an existing Vector configuration?

Yes. Import a local YAML, JSON or TOML file, or paste its code. Sources, transforms and sinks appear on the canvas. Unknown settings stay in the configuration. Exporting in the same format without editing preserves the original text, including comments.

Can I generate YAML, JSON or TOML for Vector?

Yes. Build your configuration visually or edit it in the code view, then choose YAML, JSON or TOML when exporting. You can also import an existing file and export it in another supported format. TOML export is available when it can preserve all configuration values.

Does the tool send my configuration anywhere?

No. Parsing and editing happen in this tab. The tool has no upload API or automatic storage. Export before closing or reloading the page to keep your changes.

Can I run the exported file without Vectory?

Yes. It is a Vector configuration. Local checks use the Vector 0.58 catalog; they do not execute VRL, access your host, or validate the full runtime. Check the file with your installed Vector binary before using it. See the Vector configuration reference and the Vectory pipeline guide.

Take your pipeline to your fleet.

Export your configuration, then import it into your own Vectory server to check it, release a version, and choose which devices run it.
