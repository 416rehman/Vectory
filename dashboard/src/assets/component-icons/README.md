# Component artwork

These SVGs are bundled locally to identify the actual services a Vector component connects to. They are not Vectory marks and do not imply endorsement. The artwork is unmodified.

`provenance.json` records each exact upstream URL, SHA-256, and size. Most service assets come from the official Vector `v0.58.0` repository, matching this application's pinned Vector catalog. OpenTelemetry, Prometheus, Kubernetes, NATS, and Fluentd icons come from the CNCF's official artwork repository. All vendor/project marks remain the property of their respective owners; upstream trademark usage guidelines continue to apply.

The files are served as same-origin images. No external requests, scripts, external SVG references, or generated/imitation logos are used. Semantic Lucide icons represent components without bundled brand artwork.
