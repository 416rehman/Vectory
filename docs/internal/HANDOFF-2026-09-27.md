## Editing limits and release gates

TOML output is checked by semantic round-trip so unsupported values such as explicit null cannot be silently omitted. A format switch fails without replacing the existing code; restored/reloaded configurations fall back to complete JSON when needed.

The browser rejects non-finite numbers and whole numbers outside JavaScript's safe range, **−9,007,199,254,740,991 through 9,007,199,254,740,991**, instead of saving rounded integers. Configurations requiring larger native integers cannot currently be edited through this dashboard. Defaults containing unsafe integers remain omitted.
