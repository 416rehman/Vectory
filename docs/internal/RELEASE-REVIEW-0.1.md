The candidate's generated third-party license inventory records declared license expressions. A separate distribution review identified missing upstream copyright/license text in browser and agent materials, and corresponding-source requirements for Pagefind's compiled Help search. The repair generates the checked-in `NOTICE` from versioned upstream texts and provenance, includes it in browser assets, packages, starters, images and loose release downloads, and supplies the pinned Pagefind source and locked WASM dependencies both in Help and as release assets. Distribution checks compare these copies byte for byte and verify archive, source-input and emitted WASM hashes. The inherited Vector image already carries its original notice, third-party copyright inventory and full license files; image checks preserve those materials.

That repair requires fresh final branch qualification. Its dependency scope follows the actual bundled browser modules, Go runtime/modules, Rust normal/build graph, Vector-derived catalog, component artwork and fonts. Upstream packages that omit a copyright line or have an unavailable published source revision are identified explicitly in provenance; no copyright owner is invented. This is an engineering review of distribution materials, not legal clearance. The separate source lockfile SPDX inventory can still record `NOASSERTION` where a lockfile declares no license.
