# Release 0.1 candidate review

The reviewed code and unsigned candidate were built from `74dacc769ccf31739bfcc4d666a76d4b1f39b711`. The [nine-job checks run](https://github.com/416rehman/Vectory/actions/runs/37282511193), [native platform run](https://github.com/416rehman/Vectory/actions/runs/37282556351), [candidate run](https://github.com/416rehman/Vectory/actions/runs/37282556392) and [screenshot run](https://github.com/416rehman/Vectory/actions/runs/37282556622) all passed on that commit. The candidate's 37 listed SHA-256 digests matched its 37 other files, and `packaging/verify-release.py` accepted the complete unsigned inventory. The final publication commit will have a different SHA, so its checks and candidate must run again before the tag's downloads are published.

Independent pre-release reviewers found no new P0 or P1 issue, and no new P2 requiring a release fix. The existing P2 findings have owners and are disclosed in [Open security findings](../security/OPEN-FINDINGS.md) and the user-facing [known limits](../user/whats-new.md#known-limits). Review evidence and limits by area:

| Area | Evidence | Result and limit |
| --- | --- | --- |
| Shell, navigation, editor and pipeline creation | All eight final-head screenshots were visually inspected; dashboard and browser jobs exercised the live UI. A separate source review checked the Graph/Code switch, explicit Save/Discard behavior, inspector hierarchy, validation feedback, edge styles, node warnings and enrollment choices. | No P0–P2 found. Labels in a full-fit graph can be small; zoom and the table view remain available. |

| Agent installation, deployment and updates | Generated installer trust and checksum path, consent and update locking were reviewed; the candidate's five offline agent archives and four Linux packages were checked against their cataloged raw binaries. The native run exercised services, hostile offers, interrupted updates, rollback and opt-out on Ubuntu 24.04, macOS 15 and Windows Server 2025. | No new P0–P2 found. Reboot, power loss, upgrades from older releases and older operating systems remain outside the tested matrix. |
| User documentation and compatibility | Link, writing, requirements, CI-table and version checks; Help center tests; reviewer comparison of installer, capability and deployment claims with implementation. | No contradictory activation claim found. Documentation calls the release unsigned and distinguishes a download from verified activation. |
| Security and release artifacts | Independent image and dependency review, exact candidate inventory and package inspection, and Compose HTTPS/health/agent-path integration. Trivy scanned the candidate image archives and pinned proxy with the database and counts recorded in [Dependency audit](DEPENDENCY-AUDIT.md). | No critical record in the final image scans. Remaining high operating-system package records and the temporary HTTP/1.1 proxy limit are disclosed; they require recheck with a current advisory database before publication. |

This review is targeted, not an exhaustive adversarial audit of every final binary. The unprobed paths are listed under [Review coverage limits](../security/OPEN-FINDINGS.md#review-coverage-limits). The separate public-history decision in [release gate 7](RELEASE-0.1.md#gates) remains open; this review does not approve a tag or a release.
