# Release 0.1.1 (developer preview)

This patch fixes the Linux amd64 preview kit's validator connection on Docker 29. The 0.1.0 kit requested a loopback host mapping for an internal-only validator network. Docker 29.1.3 retained that requested mapping in the container configuration but exposed no runtime port; the preview's structure checks could run while native Vector validation was unavailable. The 0.1.0 tag and published assets remain unchanged.

The preview now starts its own validator first, checks the Compose project, service, image, internal bridge, IPv4 endpoint and absence of published ports, then points the host-networked manager directly at that private address. Both proxy-exclusion variables include the checked worker address. Startup verifies worker health from inside the manager before reporting success. Every start re-inspects the endpoint, while stop and resume retain the database and certificate authority. Inherited image, port or endpoint values cannot override the checked generated Compose configuration.

The validator remains on one internal network with its existing non-root account, read-only filesystem, dropped capabilities, no-new-privileges setting, temporary filesystem and resource limits. The server kit already connects to its validator over their shared internal network and does not need this topology change. Ordinary installation continues to use prebuilt images and requires no compiler or additional JSON-processing tool.

The version declarations and generated API version metadata move to 0.1.1 without changing dependency versions, API routes or wire schemas. Current documentation, starter examples and notice provenance follow that version. Historical 0.1.0 qualification records remain as evidence for that release.
