# Vectory visual direction

The user selected https://base44.com/ as a visual reference (reviewed 2026-09-26). Vectory borrows general techniques: warm off-white surfaces, strong black typography, orange action accents, cobalt blocks, fine grid textures, open spacing and square registration details. All branding and product compositions are original. No Base44 assets, proprietary typefaces, copy, or logos are bundled.

The dashboard uses local system typography and Lucide SVG icons. There are no runtime font/CDN requests or phone-home analytics. The illustrated flow on the overview is a static explanation of source → transform → sink, not a claim about fleet throughput. Every metric, device and activity row comes from the authenticated Rust API. Test screenshots depict explicitly synthetic native integration fixtures.

Light/dark tokens, reduced-motion preferences, mobile navigation, visible focus, native labeled controls, accessible Radix dialogs, and React Flow keyboard controls are implemented. A keyboard connection form supplements dragging handles. The canonical Vector JSON model retains unknown fields independently from canvas layout.
