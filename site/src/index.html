Control belongs in the right places

A clearer boundary between what you want and what runs.

Vectory is self-hosted. Your event stream goes from Vector to your destinations; it does not pass through Vectory.

01 / RELEASE

Versions that stay put.

Publish an immutable configuration, compare it with earlier versions, and review who should receive it before deploying.

02 / HOST

Devices keep a say.

Restricted mode and local allowances are set on each host. The server cannot widen them; supported credential fields can use host-held secrets.

03 / EVIDENCE

Status with a reason.

See the version a device reports running, the stages it passed, and the issue that stopped it. File delivery alone is never called activation.

Prebuilt images. Docker Compose. No compiler.

01 / YOUR SERVER

Choose your OS.
Start your server.

Use Docker Engine on Linux or Docker Desktop on Windows and macOS. The installer gets the prebuilt release and guides you through HTTPS. No Rust, Go or Node toolchain is needed.

  1. 01
    Run the installerDownload it to your server, then run it from your terminal.
  2. 02
    Enter your domainPoint it at your server. HTTPS is set up automatically.
  3. 03
    Open VectoryCreate the first administrator, then connect a device from the dashboard.
Terminal · Docker Engine and Compose ready
curl -fsSL --proto '=https' https://vectory.ahmadz.ai/install.sh -o vectory-install.sh && bash vectory-install.sh
Terminal · Docker Desktop running
curl -fsSL --proto '=https' https://vectory.ahmadz.ai/install-desktop.sh -o vectory-install.sh && bash vectory-install.sh

Intel and Apple silicon. On Apple silicon, enable amd64 emulation in Docker Desktop, then confirm the installer prompt.

PowerShell · Docker Desktop in Linux mode
curl.exe -fsSL --proto '=https' https://vectory.ahmadz.ai/install.ps1 -o vectory-install.ps1; if ($LASTEXITCODE -eq 0) { powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\vectory-install.ps1 } else { throw 'Installer download failed' }
Start with the quickstart ↗ Download the Linux installer to review it, or use the manual install guide.
02 / YOUR DEVICES

Download.
Run. Connect.

Open Add device, choose one device or many, then Linux, macOS or Windows. Copy one command from your server. It detects the CPU, downloads and verifies the native agent, and applies your settings.

  1. 01
    Choose the host permissionsRestricted allowances or full Vector mode, with your own service and path settings.
  2. 02
    Run the generated commandLinux and macOS Terminal, or Windows PowerShell. Vector 0.58.x must already be installed.
  3. 03
    Reuse it across your fleetSet a token limit, expiry and allowed names. Paste the token privately or provision a protected token file for automation.
See the device setup ↗ The agent connects out to your server. Your events stay with Vector.
